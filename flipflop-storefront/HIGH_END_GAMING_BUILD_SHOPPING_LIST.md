## How to Use This List

Each section includes:
1. **Component Name** — What you're looking for
2. **Sketchfab Search Prompt** — Copy-paste directly into Sketchfab search
3. **File Format** — Preferred format
4. **File Size Target** — For performance
5. **Installation Path** — Where to place it
6. **Notes** — Special considerations

### Copy-Paste Instructions:

1. Open: https://sketchfab.com/search
2. Copy the search prompt from "Sketchfab Search Prompt"
3. Paste into search bar
4. Filter by: License (CC0 or CC-BY) + Downloadable (Yes)
5. Download glTF or GLB version
6. Place in the installation path

## Pro Tips

- **RGB Search:** Add "RGB" to nearly every search for better results
- **Premium Brands:** Look for Corsair, NZXT, Lian Li, Noctua, G.Skill, Kingston, Samsung
- **File Sizes:** Cases will be largest (1-3.5MB each)
- **Lighting:** Prefer models showing RGB/LED lighting clearly
- **Chrome/Mirror:** For Lian Li Dark Mirror, emphasize "chrome" OR "mirror" in searches
- **Glass:** For aquarium cases, emphasize "tempered glass" or "glass panels"
