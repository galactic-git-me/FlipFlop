================================================================================
SKETCHFAB TIPS
================================================================================

Search Strategy:
- Use specific terms: "RTX 4090", "DDR5", "NVMe"
- Or generic terms: "graphics card", "memory", "hard drive"
- Adjust if no results found

Filter Options:
1. License = CC0 or CC-BY (not required - just recommended)
2. Downloadable = Yes (required)
3. Sort by Popular (good quality indicator)

Download Format:
- Prefer: GLB (glTF binary - self-contained)
- Alternative: glTF (requires textures in same directory)
- Avoid: FBX, OBJ (not supported by configurator)

File Placement:
- Extract downloaded ZIP
- Find .gltf or .glb file
- Rename to variant-{N}.gltf (e.g., variant-1.gltf)
- Move to public/models/{type}/

================================================================================
TROUBLESHOOTING
================================================================================

Model doesn't appear in configurator:
  1. Check file exists: ls -la public/models/gpu/variant-1.gltf
  2. Check browser console (F12 > Console)
  3. Look for "Failed to load model" errors
  4. Verify file path in error matches your file location

Textures appear white/blank:
  1. Use GLB format instead of glTF (simpler)
  2. If using glTF, ensure texture files are in same directory
  3. Check .gltf file references texture paths correctly

Download is slow:
  1. Choose simpler models (fewer polygons)
  2. Download GLB format (often smaller)
  3. Try a different model from Sketchfab

File doesn't download:
  1. Check you have internet connection
  2. Verify Sketchfab model is marked "Downloadable"
  3. Try a different browser if download fails
  4. Some models may require accepting license terms
