### Step 4: Handle Dependent Files
If a model has `.bin` files (binary data) or separate texture files:
- **Keep them in the same folder** as the `.gltf` file
- They link automatically to the main model file
- Example:
  ```
  public/models/gpu/
  ├── variant-1.gltf      (main model file)
  ├── variant-1.bin       (binary data - keep here!)
  └── textures/           (if present - keep here!)
  ```

### Step 5: Verify Directory Structure
```bash

ls -la ~/CODING/FlipFlop/pc-flipper-customer/public/models/cpu/
# etc.

# Should see: variant-1.gltf, variant-2.gltf, variant-3.gltf in each folder
```

## Sketchfab Pro Tips

### Finding the best models
1. **Sort by popularity**: Most downloaded models are usually good quality
2. **Check reviews**: Look at model preview carefully before downloading
3. **Filter by license**: Make sure it says CC0 or CC-BY
4. **Filter downloadable**: Must have Download button available
5. **Check file size**: Shown on model page before downloading

### Understanding Sketchfab file sizes
- Sketchfab sometimes shows "uncompressed" size
- Actual .glb downloaded file is usually much smaller
- Don't worry if preview size shows 5MB — downloaded glTF often 500KB-1MB

### License requirements
- **CC0**: Public domain, no attribution required (preferred)
- **CC-BY**: Requires attribution in code or documentation
- **Other licenses**: Check if commercial use is allowed
- **Always verify** before downloading — read license info on model page

## Troubleshooting

### Model won't download
**Problem:** Sketchfab download button is grayed out or missing

**Solution:**
1. Check the model's license (must be CC0 or CC-BY)
2. Try a different browser
3. Try a different model from the same search
4. Use the alternative search terms provided above

### File format is wrong
**Problem:** Downloaded a .blend, .obj, or .fbx file instead of .gltf/.glb

**Solution:**
1. Go back to Sketchfab
2. Click **Download** again
3. Select **glTF** from the dropdown (not Blender, OBJ, or FBX)
4. If glTF isn't available, choose a different model

### Model appears too small or large
**Problem:** Model doesn't match the scale of other components

**Solution:**
1. Still works! The configurator scales models automatically
2. Fine-tuning happens in `lib/model-manifest.ts` if needed
3. Can adjust `COMPONENT_SCALES` in that file
4. Or rescale model in Blender before uploading (advanced)

### Model doesn't load in configurator
**Problem:** Blank space where model should be, or console error

**Solution:**
1. Check **browser console** (F12 → Console tab)
2. Verify file exists in correct folder: `public/models/gpu/variant-1.gltf`
3. Check file path in `lib/model-manifest.ts`
4. Validate model: Try in https://gltf.report/ (paste file contents)
5. Check CORS: If error mentions "CORS", the file might be in wrong location

### Performance is sluggish
**Problem:** Slow loading or lag when swapping models

**Solution:**
1. Reduce file sizes (use compression above)
2. Check total loaded size in DevTools → Network tab
3. Consider removing unused variants
4. Profile performance in DevTools → Performance tab
