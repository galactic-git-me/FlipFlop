# FlipFlop Selling Principles — PC Build Listings

Applied automatically to every AI-generated eBay title and description.
Edit this file any time; changes take effect on the next listing generated
(no code change needed).

## Title

- Front-load the exact searchable specs buyers filter/search by, in this
  order: CPU model, GPU model, RAM size, storage size/type. E.g.
  `Custom Gaming PC – Intel i7-13700K, RTX 4070 Ti, 32GB DDR5, 1TB NVMe SSD`.
- Use the **exact** model number — never a vague category like "gaming PC"
  or "fast computer". A wrong or missing digit/letter measurably lowers
  buyer trust and search visibility.
- Lead with recognizable brand names buyers actually search for (NVIDIA,
  AMD Ryzen, ASUS ROG, Corsair) — they carry built-in trust.
- No filler/hype words ("AMAZING", "L@@K", excess capitals/emoji in the
  title) — these read as low-trust to experienced buyers and can trip
  eBay's spam filters.
- Stay within ~80 characters; every word should be a real search term.

## Description structure

1. **Spec table up top** — CPU, GPU, motherboard, RAM (size + speed),
   storage, PSU (wattage + rating), case, cooling. Bullet points, not
   prose paragraphs — buyers scan, they don't read.
2. **Benchmark numbers / real FPS in 1-2 popular games**, if available —
   this is the single strongest trust/value signal for a gaming PC and is
   exactly what the performance card exists to provide.
3. **Condition and usage history stated honestly** — build date, hours of
   use, whether overclocked, any cosmetic wear. Specificity here reads as
   trustworthy; vagueness reads as hiding something.
4. **What's included vs not** — peripherals, original boxes, extra
   cables, driver discs. Items "with the box and everything" consistently
   sell for more than bare units.
5. **OS status** — fresh install / licensed / no OS. State it explicitly.
6. Skip melodramatic sales copy ("bid confidently!", "don't settle for
   plastic gaming PCs!") — it reads as amateur. Confident, factual,
   specific language outperforms hype for high-value tech buyers.

## Trust signals

- Mention any remaining manufacturer warranty on individual parts (GPU
  and PSU especially — these often carry 3–5 year warranties that
  transfer to a new owner). This is a real differentiator worth stating.
- A stated return window increases buyer confidence and conversion.

## Photos (biggest lever for "premium" feel)

- Even, soft lighting — natural window light or a simple lamp; no harsh
  flash glare on glass/acrylic side panels.
- Clean, uncluttered background — plain wall, desk, or backdrop sheet.
- Minimum angle set: full front, side panel showing internals/cable
  management, close-up of GPU and CPU cooler branding, rear I/O panel,
  and any included boxes/accessories.
- Include one shot powered on with RGB lighting active if applicable —
  strong desirability signal for gaming builds specifically.
- Tidy cable management before shooting if it's currently messy — this
  single change disproportionately affects perceived build quality.

## Pricing

- Price against recent **sold** comps for the specific CPU+GPU pairing,
  not active/asking listings — asking prices are routinely inflated.
  Component pairing drives value far more than generic "gaming PC"
  category pricing.

## Completeness / bundling

- A complete build with matching peripherals (keyboard/mouse/monitor)
  can be worth more bundled as one listing — but check whether the
  components would be worth more sold individually first.

## Shipping (heavy/fragile item)

- A PC tower is heavy and easy to damage in transit — budget realistic
  packaging (foam/padding around the GPU especially) and be upfront
  about local-pickup vs courier options in the listing.
