## Shared library rule

A physical catalogue variant must have one shared asset identity even if it is tagged into both Curated and Custom. Uploading through either catalogue queue creates a version of that shared variant asset. A generated/uploaded file remains unavailable to the configurator until geometry/scale, source rights, and administrator review gates are satisfied.
