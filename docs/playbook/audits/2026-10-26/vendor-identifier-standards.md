# Identifier standards for the vendor HTML audit

Researched 26 October 2026 against primary documentation. This note classifies identifier types; it does not claim that any particular field is present on an audited retailer page.

| Identifier visible in HTML | Scope | Suitable as a cross-vendor product key? | Evidence |
|---|---|---|---|
| GTIN / EAN / UPC (`gtin`, `gtin8/12/13/14`, `ean`, `upc`) | GS1 trade-item identifier; UPC and EAN are common GTIN formats. Check length, check digit, exact variant and packaging level. | **Yes**, when validated and assigned to the same exact trade item. A checksum alone does not prove ownership or product mapping. | [GS1 definition](https://support.gs1.org/support/solutions/articles/43000734120-what-is-a-gs1-gtin-), [GS1 validation](https://support.gs1.org/support/solutions/articles/43000734070/), [Schema.org GTIN](https://schema.org/gtin) |
| Manufacturer part number (`mpn`, manufacturer code/part number) | Assigned by the manufacturer; identifies a product within that manufacturer's products. | **Yes, with manufacturer/brand namespace** and exact variant suffix preserved. A vendor's field labelled SKU is not automatically an MPN. | [Google MPN specification](https://support.google.com/merchants/answer/6324482?hl=en), [Schema.org MPN](https://schema.org/mpn) |
| ASIN (`data-asin`, `/dp/{ASIN}`) | Amazon catalogue identifier. Variations have distinct ASINs. Amazon associates additional identifiers such as UPC/EAN with catalogue items. | **Amazon alias only**. Useful to connect Amazon search cards, detail pages and offers, then bridge to other vendors through evidenced GTIN/MPN. It is not a GS1/global hardware identifier. | [Amazon ASIN explanation](https://sell.amazon.com/blog/how-to-create-a-new-asin-amazon), [Amazon Catalog API](https://developer-docs.amazon.com/sp-api/docs/catalog-items-api-v2022-04-01-reference) |
| eBay ItemID / legacyItemId / REST itemId | eBay listing or specific variation identifier. A legacy parent listing can cover several variations. | **No**. Keep as a source-listing key; include variation when applicable. | [eBay Browse ID semantics](https://developer.ebay.com/api-docs/buy/static/api-browse.html), [eBay ItemID definition](https://www.developer.ebay.com/DevZone/merchandising/docs/CallRef/types/Item.html) |
| eBay ePID | Product identifier within eBay's catalogue, distinct from a seller's listing ID. | **eBay catalogue alias only**. It can group eBay catalogue-linked listings; it is not an EAN or manufacturer part number. | [eBay ePID definition](https://www.developer.ebay.com/support/knowledge-base/1475) |
| Google Merchant `id`, `offerId`, API product resource ID | Merchant-assigned offer ID (often the merchant SKU), scoped by account and resource/feed/language fields. | **No**. Distinguish these from manufacturer GTIN/MPN attributes supplied alongside the offer. A public Shopping page's opaque IDs must not be assumed to be GTINs or Merchant IDs without evidence. | [Google Merchant ID specification](https://support.google.com/merchants/answer/6324405?hl=en), [current Merchant resource identifiers](https://developers.google.com/merchant/api/guides/compatibility/products?hl=en) |
| Retailer SKU, `product_id`, `data-product-id`, cart ID, database ID | Merchant-specific record/offer identifier unless the retailer explicitly identifies its value as a manufacturer code or GTIN. | **No by default**. Preserve as `(vendor, id)` for repeat captures and provenance. A standard HTML/Schema.org property name does not make its value globally standard. | [Schema.org SKU definition](https://schema.org/sku), [Google unique-product-identifier guidance](https://support.google.com/merchants/answer/160161?hl=en) |

## Consequences for FlipFlop

Capture both layers: retailer/platform IDs for stable source records, and GTIN plus brand/MPN for cross-vendor identity. Product title/model/specification matching is supporting evidence where strong identifiers are absent, not a reason to relabel a retailer SKU as an MPN. Google explicitly advises against placing internal SKUs or guessed values into GTIN/MPN fields. [Google guidance](https://support.google.com/merchants/answer/160161?hl=en)

For JSON-LD, `sku`, `mpn` and `gtin` are different properties with different meanings. Scope a Product object to its product URL/card; unrelated recommendations elsewhere on the page must not donate their identifiers to the captured item. This scoping recommendation is an engineering inference from the properties' defined meanings, not a claim of universal vendor markup behaviour.
