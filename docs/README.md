# Documentation index

Project documentation is grouped by purpose:

- `agents/` — agent operating notes.
- `data/` — database, catalogue, and data reference material.
- `design/` — design system and interface guidance.
- `engineering/` — architecture, API, admin, service, media, and component setup.
- `guides/` — operational and product how-to guides.
- `integrations/` — marketplace, supplier, and external-service integrations.
- `marketing/` and `prd/` — product requirements and marketing plans.
- `operations/` — development, deployment, and release procedures.
- `plans/` — active and historical implementation plans.
- `playbook/` — playbook content, specifications, audits, and release evidence.
- `product/` — product policy, lifecycle, and strategy.
- `reports/` and `research/` — audits, research, and historical findings.
- `superpowers/` and `testing/` — design/implementation records and test guidance.
- `routers/` — the workspace maps formerly at the project root.

Some Markdown files remain beside code because the application or developer tooling loads them from fixed paths (for example, agent instructions, runtime prompts, dispatch templates, and generated browser reports).
