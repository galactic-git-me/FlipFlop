Status meanings:

- **Implemented:** code path exists; verification level is stated separately.
- **Partial:** a usable foundation exists but the end-to-end customer promise is incomplete.
- **Planned:** specified but not implemented.
- **Gated:** implemented behind an external approval or disabled production flag.
