### Responsive Breakdown
- **Mobile (< 768px):** Single column
- **Tablet (768px - 1024px):** 2 columns
- **Desktop (> 1024px):** 3 columns
- **Ultra-wide (> 2048px):** Full layout as shown

## Spacing & Typography Scale

```
HEADINGS:
h1 (Build Name)     40px  • Bold     • Color: #000
h2 (Section Title)  24px  • Bold     • Color: #000
h3 (Feature Title)  16px  • Bold     • Color: #000

VALUES:
Large Numbers       32px  • Bold     • Color: #667eea (prices)
Medium Numbers      18px  • Bold     • Color: varies by type
Small Numbers       14px  • Regular  • Color: #666

LABELS:
Section Labels      13px  • Bold     • UPPERCASE • Color: #999
Descriptions        16px  • Regular  • Color: #666
Body Text           14px  • Regular  • Color: #666
Fine Print          12px  • Regular  • Color: #999

SPACING:
Padding (Cards)     24px  (internal)
Padding (Sections)  40px  (sides & top/bottom)
Gap (Grid)          20-24px (between columns)
Line Height         1.6   (readable paragraphs)
```

## Typography Hierarchy

```
Level 1 (Most Important - 40px)
└─ Build Name
   └─ What the buyer sees first

Level 2 (Important - 24px)
└─ Section Titles
   └─ Company Story, Component Specs, Why Special

Level 3 (Secondary - 18-16px)
└─ Component Names, Feature Titles
   └─ Values and key information

Level 4 (Tertiary - 14px)
└─ Descriptions, Body Text
   └─ Details and explanations

Level 5 (Fine Print - 12-13px)
└─ Labels, Subtitles
   └─ Context and metadata
```

## Visual Polish Details

✨ **Shadows:** `0 20px 60px rgba(0, 0, 0, 0.1)` on hero
✨ **Border Radius:** 12px on cards and containers
✨ **Transitions:** 0.2s on hover states
✨ **Gradients:** Always 135deg for consistent direction
✨ **Spacing:** Consistent 24px base unit throughout
