# Catalogue component 3D references

This library contains reusable source photography for catalogue components. It is
independent of customer builds: a build selects catalogue assets, but does not own
or create them.

## Structure

Each leaf directory is a visually distinct 3D family rather than a performance
variant. Capacity, clock speed and efficiency-rating choices reuse the same family
when their exterior geometry is unchanged. `manifest.json` records the curated
variant names covered by each family and the source/provenance for every image.

PC chassis are intentionally excluded. They need a separate design decision before
references are sourced.

## Usage and rights

These files are professional product references for internal model-generation and
evaluation. Manufacturer or publisher ownership is retained. No file is marked as
approved for redistribution, storefront publishing or model-output promotion until
the corresponding rights review has been completed.

For Meshy, prefer three or four distinct views of a family. Do not combine images
from different representative products in one generation job.
